“Activation” day 2 - recap here or here

📢📢📢

Quick recap to avoid the agent sprawl across the enterprise. Make sure to correctly implement your Agent Lifecycle Management (for managing the army of AI agents):
Conception -> Governance -> Monitoring -> Retire

Customer eXperiences about their ALM:

  • IBM: AskHR tool to introduce generative AI with chatbots to employees which moves to a (domain specific) agentic AI with WatsonX. Agent collaboration is key here for a unified eXperiences to the end-users.
  • United Airlines: Reliability and safety is top priority (get to the truth fast!). AI needs to scale the diagnostic cycle for this. It’s a processing flow between AI Triage Agent, Custom Diagnostic Agent, and the Content Aviator AI of OpenText.
  • Pick n Pay: DevOps Aviator (delivery and deployment platform) to get software into production at scale. For this you want to create userstories fast and testcases with detailed steps. It’s all in context of the enterprise data (including video data).
  • Honda: Trading Grid Online on failed transactions takes a long time. Aviator Studio can do this now faster and at scale introduction a minimal downtime with an adaptive context-aware and self-learning automation.
  • SLB: Monitoring and logging at scale. You want to resolve a problem quickly (problem -> diagnose -> resolve). AI powered root cause analysis can create a topology with event details based on company data (the context). Aviator can answer questions on these events to quickly get to the root cause of the problem.

Good to understand: On the OpenText AI data platform, OT will create its own agents. Customers can add their agents too and that’s where the orchestration starts to bring value over workflows that chain the army or agents with global content (from the world) and domain specific content (from the customer).

The steps of Aviator Studio implementation:

  1. Create an Agent
    • Set name and description
    • Define tasks and goals (for the agent)
    • Add tools
    • Add knowledge sources
    • Save agent
  2. Assemble Agents into a Workflow
    • Add agents to workflow
    • Define tasks and goals (for the workflow)
  3. Testing Agents
    • Select an agent and simulate it
    • View agent progress and results
